## 归档约定

- 日报：`daily/YYYY/MM/YYYY-MM-DD.md`，日期使用北京时间（Asia/Shanghai）
- 月索引：`archives/YYYY-MM.md`，按日期从新到旧排列
- 月份导航：本页按月份从新到旧列出已发布索引
- 首页：链接最近一期实际发布的日报，并保留本页与主题导航
- 每篇日报包含实际采集截止时间和发布时刻；补发注明补发，未发布的日期不伪造记录

每个月度索引使用以下列：

| 字段 | 内容 |
| --- | --- |
| 日期 | 日报所属北京时间日期 |
| 日报 | 指向完整日报的相对链接 |
| 重点 | 2–4 个简短主题或成果名，仅概括当日实际内容 |
| 方向 | AI4Sec、Sec4AI 或二者 |
| 条目数 | 当日实际收录总数，必要时注明新闻 / 项目 / 论文分布 |

每个月度索引另设条目级表格，逐项保留日期、方向（AI4Sec / Sec4AI）、类型（news / project / paper）、固定主题标签、标题与指向正文的条目锚点。同一成果只保留一条主记录。

正文只保存在对应日报，索引提供导航。跨月更新引用原记录；历史更正保留原链接，并同步修正受影响的索引描述。

## 按日期查找

在仓库文件列表按路径进入目标年、月，或使用 GitHub 文件查找搜索完整日期。全文主题查询见[检索说明](../topics/README.md#检索方法)。GitHub 搜索可能需要登录，新提交的内容也可能尚未完成索引；目录导航不依赖搜索索引。
