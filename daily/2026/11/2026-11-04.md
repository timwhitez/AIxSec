## 要点

本期最值得借鉴的不是更大的 Agent 编队，而是把不同验收目标分开：代码排序好，不等于能识别补丁；流量粗分类好，不等于能准确归因；攻击网页更少进入上下文，也不等于攻击成功率已下降。另一项实际案例表明，全局指令和 Skills 应进入配置变更审计，不能只扫描可执行文件。

## 1. Prompt Adware：第三方配置如何长期影响 Agent

**Sec4AI · news/research · 2026-11-03** · `prompt-injection` / `ai-supply-chain` / `agent-tool-security`

**来源与贡献。** Check Point Research（Pedro Drimel Neto）的 *Free the Model, Sell the Gateway: Prompt Adware hidden in Jailbreak Bundles* 分析 Haiou 4.5.0。值得注意的是第三方包对可信指令的持久改写，研究没有证明企业信息已经被窃取。发现样本和实施测试的具体日期未明确。[技术报告](https://research.checkpoint.com/2026/free-the-model-sell-the-gateway-prompt-adware-hidden-in-jailbreak-bundles/) · [官方说明](https://blog.checkpoint.com/security/prompt-adware-how-hidden-ai-instructions-could-create-a-new-enterprise-security-risk/)

**问题与机制。** 前提是用户安装增强包并允许它修改全局代理配置，不是仅浏览网页。按 CPR 样本分析，安装器校验、解密包内提示模块与六项 Skills；广告规则位于 `00-identity.md`，进入全局指令后，后续 Codex 会话的特定问候会触发第三方网关推广。影响跨越原安装会话，因此只检查当前对话输入会漏掉来源。[技术报告](https://research.checkpoint.com/2026/free-the-model-sell-the-gateway-prompt-adware-hidden-in-jailbreak-bundles/)

**证据与边界。** CPR 给出样本分析和触发演示，未给跨版本成功率或系统性样本量。Claude Code 在作者测试中拒绝相关注入，不能据此概括所有版本。CPR 未发现被推广网关恶意，也未观察到 Haiou 窃取企业信息；泄密与建议偏置属于进一步风险推演，不应写成已经发生的攻击结果。[官方限定](https://blog.checkpoint.com/security/prompt-adware-how-hidden-ai-instructions-could-create-a-new-enterprise-security-risk/)

**可行动启发（本文分析）。** 将全局指令、Skills 和配置纳入安装前后差异、批准来源及回滚审计；验收既看“写了哪些文件”，也看“哪些后续任务会读取它们”。哈希、签名可验证来源和完整性，不能证明自然语言内容安全。不要为了核查而在真实工作环境安装包。公开仓库主要是说明与打包物，不能等同于清晰可审计的完整源码。[项目说明](https://github.com/haiou-666/haiou-codex)

**判断：中等置信度。** 持久指令影响有原始演示支持；影响规模、稳定性和进一步攻击后果未独立验证。这里不把增强包直接定性为已发生的供应链攻击。

## 2. Cyber-JEV：漏洞数据的来源，可能变成模型的答案

**AI4Sec · paper · 近期补读** · `code-security` / `cyber-model-training` / `cyber-training-data` / `cyber-model-evaluation`

**来源与时间。** Zhuyi Zhao、Shengjie Yuan 等，*Cyber-JEV: Matched Contrastive Fine-Tuning of Language Models for Fast Source-Code Vulnerability Triage*。v1 于 11 月 2 日 11:24 UTC 提交；v2 于 11 月 3 日 11:36 UTC 增加项目页，手稿未改。当前按预印本处理，未见同行评审录用声明。[版本记录](https://arxiv.org/abs/2611.02957v2)

**背景与新增设计。** 混合正常代码数据和“只有漏洞”的公开修复记录，模型可能学会用项目风格猜标签。Cyber-JEV 从修复提交构造 2,829 个对照组，包含漏洞函数、修复版本和最多两个同文件未改函数。参考数据承担分类损失，外部记录只承担组内排序；共享的加性来源偏移在组内比较中抵消，但这不证明所有捷径都被消除。推理只接收单个函数并输出风险分数，不生成漏洞解释。[方法说明](https://github.com/RicardoZ-kisara/cyber-jev/blob/34df8c3c17f9bc278bc8d8c5dbd2e8c0880173d0/method.html)

**训练与证据。** 作者对 Qwen3.5-4B 做 LoRA；按项目、CVE、修复提交、哈希及近克隆关系隔离受保护切分。7,270 个测试函数中有 322 个漏洞，五模型集成 AUROC 为 0.814，Jev 1.13 为 0.743；同为 4,031 条告警时漏报为 16 对 39。长函数组先无激活保存地计算分数，再重算反传，节约峰值显存；两遍训练模式及 dropout 不同，作者承认是近似梯度。[论文方法与表 III–IV](https://arxiv.org/html/2611.02957v2)

**反证比单一排名更重要。** 只用参考数据训练已有 0.804；source-logit adjustment 的 AUROC 更高，为 0.825。完整方案的 T271 补丁配对成绩为 47.6%，虽高于参考数据训练的 32.8%，仍不足 50%；按平局半分的同一口径，Jev 为 50.7%。因此不能写成“全面最优”或“已可靠理解修复”。这里体现总体排序与局部修复辨别的权衡。[作者结果及计分口径](https://github.com/RicardoZ-kisara/cyber-jev/blob/34df8c3c17f9bc278bc8d8c5dbd2e8c0880173d0/results.html)

**成本与可复现性。** 主实验 LoRA rank 16、三 epoch；五模型集成每函数需要五次前向，不是总共一次。已读材料未提供可核算的完整 GPU 小时或同环境部署吞吐。项目明确不发布训练实现、权重、数据和实验记录，网站仓库不是开源模型；不能据此推荐直接部署。[固定版本可得性说明](https://github.com/RicardoZ-kisara/cyber-jev/blob/34df8c3c17f9bc278bc8d8c5dbd2e8c0880173d0/README.md)

**可行动启发（本文分析）。** 安全模型训练的验收应并列总体排序、补丁配对、未见来源误报和固定人工审查预算。补丁或同文件未改函数是弱负例，不等于无漏洞；单函数输入也不能完整覆盖跨函数因果链。下一项验证应检查去掉来源特征后的受控收益，而不是只增加漏洞正样本。

**判断：中等置信度。** 方法与反例有报告支撑，核心训练材料不可得，效果未独立复现；它是有价值的训练设计案例，不是已验证的生产审计替代品。

## 3. TrafficInstruct：先定义观察和标签，再谈安全 SFT

**AI4Sec · paper/dataset · 近期补读** · `detection-response` / `cyber-training-data` / `cyber-model-training` / `cyber-model-evaluation`

**来源与贡献。** 中国科学技术大学 Zhengdao Li 等，*TrafficInstruct: A Multi-Task Network Traffic Dataset and Benchmark for Instruction Tuning*，11 月 2 日 15:44 UTC 的 v1，未见录用声明。增量主要是新采集数据、标签依据和评测协议，不是新 LoRA 算法。[论文记录](https://arxiv.org/abs/2611.03319v1)

**输入到输出。** 资源描述包含 55,000 条 SFT 记录及对应 PCAP，覆盖恶意流量、Botnet、DoH、Web、APT、VPN/Tor、应用和网站识别等十任务。受控采集的进程、活动与执行记录支持标签；模型只应看到任务允许的流、窗口或访问轨迹字段，输出结构化分类。完整采集 session 不跨训练、验证、测试，关联视图继承同一切分。这防止同活动泄漏，不代表跨设备、网络或新环境泛化。[固定版项目概览](https://github.com/zhengdao-li/TrafficInstruct/blob/35738d20bed4cfb8eb26435cf947eca0317a1f6c/README.md)

**训练与关键比较。** 实验是冻结的 Qwen3.8-27B 加分别训练的任务 LoRA，不是联合训练的通用多任务模型。作者报告恶意流量粗检测 Macro-F1 为 93.5%，家族分类却只有 52.7%，后者低于 ET-BERT 的 62.3%；Tor 活动细分类中，随机森林为 65.7%，LoRA 为 52.8%。较大模型的收益随任务和标签粒度变化，不能用粗检测分数代替归因能力。[论文表 IV–V](https://arxiv.org/html/2611.03319v1)

**成本与有效性限制。** 参考训练用八张 RTX PRO 6000、五 epoch、rank 8；未披露可核算的总 GPU 小时和部署延迟。ET-BERT 的结构化字节输入与大模型的任务文本预算不相同，单 seed 结果不是等预算架构优劣证明。APT 输入仍含标识符与上下文，尚不能排除捷径；所谓 concept drift 任务仍评估应用身份分类，不是在线漂移检测器。[实验和局限](https://arxiv.org/html/2611.03319v1#S5)

**数据可得性存在具体落差。** 论文 VI-B 描述仓库中的下载链接和访问码；核查时仓库却明确要求邮件申请，不公开链接或访问码。未见数据文件、训练代码、模型权重及独立 LICENSE。数据尚未取得，许可与复现实验不能视为已解决。[实际访问说明，提交 35738d2](https://github.com/zhengdao-li/TrafficInstruct/blob/35738d20bed4cfb8eb26435cf947eca0317a1f6c/README.md)

**可行动启发（本文分析）。** 建设流量训练集时，将“用于判定标签的主机证据”和“上线实际能观察的网络字段”分开存储，明确采集单位与切分单位。投入训练前，应取得可核验的 session 清单、使用许可、标识符去除消融和同预算强基线；否则高分可能来自不可部署的上下文。

**判断：中等置信度。** 论文提供细致协议和可解释的负面结果，但受限数据、单次训练及未排除的捷径限制了泛化判断。当前适合借鉴数据协议，不能称为完全公开可复现的训练资源。

## 4. SearchInject：少看见攻击页面，不等于已阻止攻击

**Sec4AI · paper · 近期补读** · `prompt-injection` / `ai-security-evaluation`

**来源与时间。** Kainan Zhou 等，*SearchInject: Retrieval Exposure Control for Indirect Prompt Injection in Language-Model Search*，11 月 2 日 07:04 UTC 的 v1。作者称为 IEEE ICCC 2026 accepted manuscript，本期未独立核验会议录。[版本记录](https://arxiv.org/abs/2611.02643v1)

**问题与实现。** 间接注入载体必须进入上下文才可能影响模型。SearchInject 在检索后、上下文组装前，用逻辑回归组合相关性、搜索滥用线索、指令特征及相关性交互项；从前 100 个候选中隔离超阈值页面，其余维持原排序并补足十条。这是检索准入控制，不是生成模型后训练。[方法](https://arxiv.org/html/2611.02643v1#S3)

**结果及不能推出的结论。** 300 个保留 SciFact 查询、每个四种构造中，BM25 的目标页面暴露率从 94.08% 降至 15.83%；干净 NDCG@10 最大下降 0.0018。可是 104 例生成检查中，无防御组也没有确认成功的劫持，且评分终点事后制定。因此约 83% 的相对下降只指载体进入上下文，不能写成攻击成功率下降。测试误隔离率 0.59%–0.65% 也高于校准集的 0.5% 约束。[结果表 II–VI](https://arxiv.org/html/2611.02643v1#S5)

**比较与复现边界。** 四类页面构造开发时都见过，未评估现代稠密检索或防御感知攻击；组件未按相同误隔离率比较，交互项贡献未被受控消融确认。同查询的四个结果不应当四个独立样本。原始候选记录及训练产物不可得，随文材料只能重建汇总图和解析区间，不能重放实验。摘要中的 artifact 链接指向会议首页，并非可核验实验包。[局限与复现声明](https://arxiv.org/html/2611.02643v1#S6) · [摘要所链页面](https://www.iccc.org/)

**可行动启发（本文分析）。** 安全验收应同时保存补位前后候选、载体暴露、实际越权结果和合法任务完成率。降低阈值会拒绝更多候选，但补位也可能把原本排在十名之外的攻击页送进来，收益未必单调。先构造确实能成功的无防御攻击，再在相同误拦成本下比较防御。

**判断：中等置信度。** 支持给定构造内的检索暴露控制，不支持已证明的下游防护收益。完整部署时延和算力未报告；论文为 CC BY 4.0，未核验独立实验代码许可。
