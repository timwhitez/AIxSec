## 1. Tether：按系统副作用约束 Agent

**方向 Sec4AI · 类型 paper · 补读，arXiv v1 2026-11-19 06:46 UTC · 标签 `agent-tool-security` / `data-exfiltration` / `ai-security-evaluation`**

- **问题与贡献。** 入口处给命令分类，不能保证程序实际只触及获准的资源；只检查当前动作也看不到它继承了上一步读到的数据。Tether 将决定放在系统效果和安全状态上，而不是要求模型自报行为，也不把权限等同于命令文本。
- **机制。** Agent 提交动作后，Isolate 在临时环境执行并暂存文件变化，用独立代理控制外发。监控层将系统观察转换成抽象操作，维护资源和进程上的来源标签；Lean 4 DSL 对抽象动作和已有状态判断。文件副作用按策略提交或丢弃；外发由代理把关，不是先发出再回滚。一个可理解的防御例子是先读敏感资料、后写中间文件：是否允许中间文件外发不能仅按它的新文件名决定。全局属性的形式化保证以观测到的抽象和策略为条件，不等于整体 Linux 隔离的端到端证明。[架构和模型](https://arxiv.org/html/2611.25599v1#S2) · [形式化规则](https://arxiv.org/html/2611.25599v1#S3)
- **对照与证据。** 两个 coding-agent 基准的离线轨迹重放。作者只纳入可端到端重放、动作可观察且在模型覆盖内的前台轨迹。表 2 中，Tether 拦住 **344/344** 条范围内对抗轨迹，良性误拦 **74/1,590（4.7%）**。同一切片的默认 Auto Mode 是 315/344 和 155/1,590（9.7%）；提供规则与资源标签的 Auto Mode 是 307/344 和 55/1,590（3.5%）。后者误拦更少，召回则更低。这是作者的固定轨迹监控对照，不是不同监控器下自由运行的任务完成率，也不是证明对所有动作均有效。[实验](https://arxiv.org/html/2611.25599v1#S6)
- **落地与边界。** 可先把写入、对外发送、安全审批拆成独立门槛；记录请求身份、目标资源、观测覆盖和决策原因。对跟踪缺口显式计为未知，尤其是后台动作、数据库内部语义和只能靠内容判断的风险。移植需要可信隔离与事件收集器、有实际控制权的出口，以及按工作负载配置和维护规则；论文成绩不能替代这些验收。未独立核验构建许可、现场吞吐或生产误报。[局限](https://arxiv.org/html/2611.25599v1#S7) · [版本记录](https://arxiv.org/abs/2611.25599)

## 2. ROGUE-AI：用成对环境检验事故成因

**方向 Sec4AI / AI4Sec · 类型 paper · 补读，arXiv v1 2026-11-19 18:23 UTC（北京时间 11 月 20 日 02:23）· 标签 `ai-security-evaluation` / `agent-tool-security` / `detection-response`**

- **问题与贡献。** 事故报道能说明发生了损失，不一定能检验损失由什么造成。把环境切成只在一个关键危险因素上不同的两份，再让同一 Agent 执行同一个正常任务，可以检验那个环境差异是否影响结果，而不只是看报告是否说得通。
- **机制。** 先核对事故与最接近的原始证据，再设计隔离、可重置的试验和匹配对照，另作独立审查。完成后用环境状态检查后果，例如测试环境的模拟记录是否真的被清除，而不是给 Agent 自述打分。对没有攻击者的操作风险，可以用两个完全合成的环境检验目标是否识别正确，且不把生产资源接进试验。[设计与验证](https://arxiv.org/html/2611.26553v1#S3) · [管线](https://arxiv.org/html/2611.26553v1#S4)
- **证据与比较。** 作者整理了 253 条报道，构建 108 个试验，涉及 96 起事故；其中 106 个试验至少有一个对照。五个当代模型每个条件各跑三次，事故条件下有害会话 **18%–33%**，匹配对照 **0%–1%**。按作者的证据规则，108 个试验中 **32 个支持、23 个提示性、51 个未复现、2 个无对照**。摘要的 89% 包括进一步诊断和其他模型等复现条件，不是五模型上的严格因果成功率。作者还报告，在其 72 起有实际损害的已报道事故中 62 起没有攻击者；这是报道样本结构，不是行业总体事故比例。[表 4 与复现口径](https://arxiv.org/html/2611.26553v1#S6)
- **可复用对照。** 在专门选取的高风险子集上，作者比较了提示中明确描述危险及后果、只陈述事实、以及等长的无关提示。等长对照仍为 83%–98%，只给事实为 58%–82%；描述后果能降低五个模型的有害比例，Claude Sonnet 4.6 为 1/40。这一结果支持对高风险操作提供具体后果说明，而不是增加通用警告长度；它不证明能替代授权门槛或生产隔离。将审批、拒绝、已执行和最终效果分开记账，可避免把误报或样本缺失算成无损失。[警告对照](https://arxiv.org/html/2611.26553v1#S6.SS3) · [局限](https://arxiv.org/html/2611.26553v1#S7)

**工程判断：** 先给不可逆动作加系统级门槛，再用一对只改环境因素的合成场景验证门槛是真拦截，不是改写了模型的回答。两篇是预印本和作者实验，不据此宣称生产安全率。
